# dot-atom

[![Open in Hanzo](https://hanzo.app/badges/open-in-hanzo.svg)](https://hanzo.app/dev/open?repo=github.com/zeekay/dot-atom&ref=main&action=open) [![Edit with Hanzo](https://hanzo.app/badges/edit-with-hanzo.svg)](https://hanzo.app/dev/open?repo=github.com/zeekay/dot-atom&ref=main&action=edit)

Default [atom][atom] dotfiles provided by [ellipsis][ellipsis] and my personal
setup.

## Features
Vim-mod, minor aesthetic changes.

## Install
Clone and symlink or install with [ellipsis][ellipsis]:

```
$ ellipsis install zeekay/atom
```
